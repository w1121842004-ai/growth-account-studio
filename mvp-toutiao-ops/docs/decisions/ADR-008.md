# ADR-008: 热榜采集源限定为头条/百度，微博仅人工导入

## Status
**Accepted（合规强制）** — 对应 blocking B-3 的能力缩减裁决。

## Background
原 PRD 计划抓取头条热榜 / 微博热搜 / 百度热搜三源。Phase 1 实测 robots 与协议：
- toutiao.com/robots.txt：`Disallow: /trending/ /item/ /group/ /search` → 热榜/正文页禁止抓取，但热榜聚合页（非 /trending/ 路径）可采，遵守频率限制。
- top.baidu.com：robots 返回 404（无明确禁止），可采热搜。
- 微博：开发者协议明确禁止采集热搜；且头条正文页 robots 禁止 → 竞争度评分不爬正文。

## Decision
- **自动采集仅限 toutiao（聚合热榜路径）+ baidu 热搜**，遵守 robots 与合理频率（如 30 分钟一次、带 UA、限速）。
- **微博不自动采集**，改为 `/hotlist/import` 人工粘贴导入（存为 weibo_import 源）。
- 竞争度评分（competition_score）基于元数据估算（如热榜排名、同类选题数），**不爬取正文内容**。

## Consequences
- 正面：合规可追溯；不踩 robots 红线；避免法律风险。
- 负面：缺失微博自动源（运营者可手动补）；竞争度为估算值，精度有限（MVP 可接受）。
- 关联：ADR-003（采集 cron）、db/schema.sql 的 hotlist_entries（source 枚举含 weibo_import）、openapi.yaml 的 /hotlist。
