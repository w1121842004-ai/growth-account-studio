# ADR-006: 大模型厂商选型（主力 / 备选 / 省钱档）

## Status
Proposed — 待 team-lead 确认后转为 Accepted。

## Background
需选定可热切换的国内大模型组合。Phase 1 联网核验了各家 API 方式、成本、速率限制、流式输出。

## Decision
| 角色 | 厂商 / 模型 | 端点 | 关键参数（核验值） |
|------|------------|------|--------------------|
| 主力 | 腾讯混元 Hunyuan Hy3 | OpenAI 兼容 | 输入 1 / 输出 4 / 缓存 0.25 元每百万 token（2026-07-06 发布价） |
| 备选 A | 智谱 GLM-4.6 | OpenAI 兼容 | RPM 60 / TPM 1,000,000 |
| 备选 B | 通义 Qwen Plus | OpenAI 兼容 | 低成本、高并发 |
| 省钱档 | 混元 hunyuan-a13b | OpenAI 兼容 | 内部评测/草稿场景降配 |

选型理由：混元为腾讯系、与 Lighthouse 部署同生态、价格透明；GLM-4.6 / Qwen Plus 作为速率或可用性兜底；hunyuan-a13b 用于非关键生成以省成本。全部支持流式输出。

## Consequences
- 正面：主力+双备选+省钱档四档，韧性足够 MVP。
- 负面：需监控三家费率变动；生成日志需按 provider 归因成本（generation_logs）。
- 关联：ADR-005（适配层）、db/schema.sql 的 llm_configs。
