# ADR-001: 采用 Next.js 16 单体架构（App Router + Route Handlers）

## Status
Proposed — 待 team-lead 确认 Phase 1 三项 blocking 修正（B-1/B-2/B-3）后转为 Accepted。

## Background
需要网页应用，面向文科背景运营者，三模块（选题/生成/排版）+ 定时采集。团队已熟悉 React 生态。
可选方案：
1. Next.js 16（App Router + Route Handlers 单体）
2. 前后端分离（React SPA + 独立 NestJS 后端）
3. 纯前端 + Serverless 函数（Vercel Functions）

## Decision
采用 **方案 1：Next.js 16.2.11（App Router）+ Route Handlers 单体**，版本锚定 React 19.2.x / TypeScript 5.x。
理由：MVP 不需独立后端服务；Route Handlers 承载 REST API；与前端同仓库同语言，文科运营者可在一个界面内完成全部操作；部署单元单一，降低运维成本。

## Consequences
- 正面：单仓库、单一语言、部署简单；Tiptap 3 所见即所得编辑器与导出预览同处前端。
- 负面：Route Handlers 不能跑长驻 node-cron（需用独立 worker 进程，见 ADR-003）；单体随规模增长需拆服务。
- 关联：ADR-003（调度）、ADR-010（部署）。
