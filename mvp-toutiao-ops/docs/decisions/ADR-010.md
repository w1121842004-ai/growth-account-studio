# ADR-010: 部署采用腾讯云 Lighthouse + Docker Compose，排除 Vercel

## Status
Proposed — 待 team-lead 确认后转为 Accepted。

## Background
需部署 Next.js 单体 + PostgreSQL + node-cron 采集进程。是否用 Vercel？

## Decision
采用 **腾讯云 Lighthouse（轻量应用服务器）+ Docker Compose**，单容器编排：next-app / postgres / cron-worker 三 service。
排除 Vercel 理由：
- Vercel 为 Serverless，无长驻进程，跑不了 node-cron 采集 worker（ADR-003）；
- 需持久化 PostgreSQL，Vercel 需外接付费 PG，成本与可控性不如自管 Lighthouse 容器；
- 国内访问延迟与备案：Lighthouse 国内地域更贴合国内 C 端运营者。

## Consequences
- 正面：进程常驻、成本透明（Lighthouse 包月）、数据自管、合规可控。
- 负面：需自行维护 Docker 与备份；MVP 后扩量需关注单机瓶颈（万级用户前无碍）。
- 关联：ADR-001（单体）、ADR-002（PG）、ADR-003（cron worker）。
