# ADR-007: 公众号/头条导出采用「复制粘贴」而非自动推草稿

## Status
**Accepted（合规强制）** — 推翻原 PRD「半自动产出草稿后发布」的自动推送前提（blocking B-2）。

## Background
原方案设想：工具生成后自动调用公众号草稿接口推送，运营者再审核发布。
合规核验：
- 微信公众平台运营规范（2026-03-27 新增）明确「非真人自动化创作行为」条款：自动推送草稿/群发可被判定违规导致封号。
- 头条无官方草稿/发布开放 API。

## Decision
**MVP 不提供任何自动推草稿/群发端点**。`/export/render` 仅返回可复制粘贴的 HTML（已含强制 AI 标识页脚），由真人复制进微信/头条编辑器手动发布。openapi.yaml 中故意不含 draft/add 或 publish 类端点。

## Consequences
- 正面：规避封号红线；满足「半自动 = 真人审核发布」真实定位。
- 负面：用户多一步复制粘贴；但这是合规代价，不可妥协。
- 关联：ADR-004（双渲染器产出可粘贴 HTML）、ADR-009（标识页脚）、openapi.yaml 的 /export。
