# ADR-005: 国内大模型接入采用 Vercel AI SDK 6 配置驱动适配层

## Status
Proposed — 待 team-lead 确认后转为 Accepted。

## Background
需求要求「国内大模型抽象为可热切换适配层」。各厂商 API 形态差异大，是否自研底座？

## Decision
采用 **Vercel AI SDK 6** 作为统一调用层。三家国内厂商（混元、智谱、通义）均提供 **OpenAI 兼容端点**，通过 `provider` 配置 + `baseURL` 切换，无需自研协议底座。
适配层读取 `llm_configs` 表（provider / model / base_url / api_key_enc / priority），运行时按优先级与可用性选路；单篇生成允许覆盖 provider/model（见 openapi.yaml /generation）。

## Consequences
- 正面：一套调用代码覆盖多厂商；热切换只需改配置表；流式输出由 AI SDK 原生支持。
- 负面：依赖三家端点持续兼容 OpenAI 协议；密钥需应用层加密存储。
- 关联：ADR-006（厂商选型）、db/schema.sql 的 llm_configs / generation_logs、openapi.yaml 的 generation 端点。
