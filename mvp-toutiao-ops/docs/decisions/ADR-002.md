# ADR-002: 数据库采用 PostgreSQL 17 + Drizzle ORM

## Status
Proposed — 待 team-lead 确认 Phase 1 三项 blocking 修正后转为 Accepted。

## Background
需要持久化热榜、选题、草稿（含富文本）、审核留痕、LLM 配置。MVP 数据量小（万级以内）。
可选方案：
1. PostgreSQL 17 + Drizzle ORM（JSONB 存 Block AST）
2. MySQL 8 + Prisma
3. MongoDB（文档模型天然适合 AST）

## Decision
采用 **PostgreSQL 17 + Drizzle ORM 0.38.x**。草稿正文以 `jsonb` 列存储 Block AST（见 schemas/block-ast.schema.json），关系型字段（用户、热榜、选题、审核）用强 schema 表。
理由：PG 的 JSONB 兼具结构化与半结构化；Drizzle 类型安全、SQL 透明、零运行时开销；全文检索可用 `pg_trgm`/tsvector（中文弱，但 MVP 用 ILIKE 足够，见架构知识库搜索模式）；腾讯云 Lighthouse 可一键起 PG 容器。

## Consequences
- 正面：单库同时覆盖关系与文档需求；迁移可控；与 Lighthouse 部署一致（ADR-010）。
- 负面：需自行维护 Drizzle 迁移；中文全文检索弱（MVP 不依赖，先 ILIKE）。
- 关联：ADR-001（单体）、ADR-010（部署）、db/schema.sql（契约）。
