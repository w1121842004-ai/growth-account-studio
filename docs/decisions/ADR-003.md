# ADR-003: 人工剪贴板粘贴放弃 draft API

## Status
Accepted — Spec §3 Out-of-Scope 锁定（2026-08-16）。

## Background
R-2：微信公众平台 2026-03 新规禁「非真人自动化创作行为」，自动推草稿/群发可致封号；头条无官方草稿/发布开放 API。原「半自动产出草稿后发布」的自动推送前提被推翻（Phase 1 强制修正 B-2）。

## Decision
**MVP 不提供任何自动推草稿/群发端点**。`POST /api/v1/drafts/:id/export` 仅「标记导出」并返回可复制粘贴的 HTML/纯文本，复制动作由前端剪贴板完成（Spec §5/§12）。openapi.yaml 故意不含 draft/add 或 publish 类端点。

## Consequences
- 正面：规避封号红线；满足「真人审核后发布」真实定位。
- 负面：用户多一步复制粘贴（合规代价，不可妥协）。
- 关联：ADR-002（双渲染器产出可粘贴 HTML）、ADR-009（标识注入）、openapi /export。
