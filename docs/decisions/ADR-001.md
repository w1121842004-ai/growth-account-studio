# ADR-001: Next.js 16.2.11 单体全栈（排除 Vercel）

## Status
Accepted — Spec §4 锁定（2026-08-16）。

## Background
MVP 需网页应用 + 后端 API + 双渲染器（Node 侧 unified/rehype 生态）。候选：Next.js 16 单体 / 前后端分离 / Vercel Serverless。
排除 Vercel 依据（R-9）：Serverless 出口 IP 动态，触发微信 40164（IP 白名单失效）；且需长驻 node-cron worker，Serverless 无长驻进程。

## Decision
**Next.js 16.2.11（App Router）单体 + Route Handlers（`/api/v1/*`，openapi.yaml 为契约）**；部署 **腾讯云 Lighthouse + Docker Compose + Caddy**（固定出口 IP，国内访问质量）。React 19.2.x / TypeScript 5.x 同仓配套。

## Consequences
- 正面：单仓库单语言；双渲染器复用 Node 生态；固定 IP 满足微信白名单。
- 负面：单体随规模增长需拆服务（MVP 阶段不提前拆）。
- 关联：ADR-002（双渲染器）、ADR-005（cron worker）、ADR-007（PG17）。
