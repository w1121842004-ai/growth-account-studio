# ADR-008: 采集源白名单与 robots 边界

## Status
Accepted — Spec AC-02/C-4/R-3 锁定（2026-08-16）。

## Background
F1 选题需热榜源。Phase 1 实测：toutiao.com/robots.txt `Disallow: /trending/ /item/ /group/ /search`；微博《开发者协议》禁采热搜；知乎/B站 robots 未在 Phase 1 核验。

## Decision
**ALLOWED_SOURCES 常量硬编码 + 单元测试**（impl/collection-worker.md 清单）。Spec AC-02 白名单：头条/hot-event、百度、知乎、B站；但：
- 头条仅采 **hot-event 聚合路径**（非 robots 禁抓的 /trending/ 路径），遵守频率限制。
- 百度热搜可采（robots 返回 404，无明确禁止）。
- 知乎/B站默认 `enabled=false`，**启用前须先核验 robots**（风险标注）。
- **微博永不采集**（协议禁采，改人工粘贴兜底，Spec §3）。
- **不抓任何文章正文**（R-3/B-3），竞争度改用共现+历史去重+LLM（AC-09）。
- 仅存标题/热度/榜位元数据。

## Consequences
- 正面：合规可追溯；不踩 robots 红线；避免法律风险。
- 负面：缺失微博自动源（运营者手动补）；知乎/B站启用前需补 robots 核验。
- 关联：db/schema.ts source_configs；ADR-005（cron）；openapi /sources。
