# ADR-009: AI 标识注入不可关闭

## Status
Accepted — Spec C-5/R-4/AC-05 锁定（2026-08-16）。

## Background
《人工智能生成合成内容标识办法》（国信办通字〔2025〕2号）第四条第二款：导出/提供功能须含显式标识且不可关闭。R-4：未注入即导出违规。

## Decision
**两个渲染器在生成平台 HTML 时强制注入页脚显式标识「本文含 AI 辅助创作」**，`disclosure_injected` 恒为 true，前端不暴露关闭开关（AC-05/§12 断言）。导出 checklist 额外提示平台侧标识：头条勾选「AI 生成/辅助创作」、公众号保留标识（C-6）。

## Consequences
- 正面：满足法定标识义务；降低平台违规与误导风险。
- 负面：无（法定义务，不可妥协）。
- 关联：renderer-rules.ts（disclosure 配置）、openapi /render（disclosureInjected）、ADR-002（双渲染器）。
