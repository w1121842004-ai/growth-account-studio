# ADR-011: Tiptap 3 / ProseMirror 对齐头条落地

## Status
Accepted — Spec §4/§7/ADR-011 锁定（2026-08-16）。

## Background
头条编辑器即 ProseMirror 内核，按 schema 白名单解析、剥内联 style（R-1 落地偏差风险）。审核编辑器选型的依据。

## Decision
**审核编辑器用 Tiptap 3（ProseMirror）**：生成工作台与审核编辑器共用；所见即所得压低「双渲染器输出 vs 头条实际渲染」的落地偏差。Tiptap 产出 Block AST → 双渲染器。编辑器本地态用 **Zustand v5**，服务端态用 **TanStack Query v5**（Spec §4），状态分离避免抖动。

## Consequences
- 正面：与头条编辑内核同源，偏差最小；文科运营者零学习成本；AST 产出自然。
- 负面：需写 Tiptap→Block AST 适配器；Tiptap 与渲染器 schema 需对齐（靠快照测试，R-7）。
- 关联：ADR-002（Block AST）、block-ast.types.ts、renderer-rules.ts、Spec §7 页面清单。
