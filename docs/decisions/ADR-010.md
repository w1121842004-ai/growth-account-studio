# ADR-010: lucide-react 单一图标源

## Status
Accepted — Spec §4/§8/P0-1 锁定（2026-08-16）。

## Background
P0 绝对规则：禁止 emoji 作功能图标、全项目不混用图标库。Spec §4/§8 锁定 lucide-react。

## Decision
**lucide-react（1.x 主版本线，以 lockfile 实际解析为准）为全项目唯一图标源**；尺寸 行内 16 / 按钮内 20 / 独立 24；**后端文档（openapi/db/架构）不出现任何图标**（图标属前端 UI 层）。功能图标一律 SVG（lucide），禁用 emoji、禁用混用其他图标库。

## Consequences
- 正面：统一视觉语言；满足 P0-1；可访问性与 tree-shaking 友好。
- 负面：无。
- 关联：Spec §8 设计 Token；前端实现约束（design-tokens）。P0 自检：本 Phase 2 后端文档零图标。
