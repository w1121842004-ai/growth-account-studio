# ADR-005: 定时仅采集、生成发布由人触发

## Status
Accepted — Spec §3/AC-02 锁定（2026-08-16）。

## Background
需周期拉热榜。是否把生成/发布也自动化？

## Decision
**node-cron 独立 worker 仅定时采集**：单并发、间隔 ≥30min、失败指数退避、只存标题/热度/榜位元数据、幂等（topics 唯一索引）。内容生成、人工审核、导出均由真人在 Web 界面点击触发，不做任何自动化流水线（半自动本质即真人把关）。

## Consequences
- 正面：cron 轻量、失败不影响主服务；零 LLM 成本；符合合规定位。
- 负面：worker 需独立于 Next.js 进程（Docker Compose 第二 service）；需保证采集失败可重试、不重复写入。
