# ADR-007: PG17 + Drizzle + JSONB，不引 pgvector

## Status
Accepted — Spec §4/§6/Out-of-Scope 锁定（2026-08-16）。

## Background
需持久化用户、选题、草稿（富文本）、编辑留痕、模型配置、源配置、用量。候选：PG+JSONB / MySQL+Prisma / MongoDB / PG+pgvector。

## Decision
**PostgreSQL 17 + Drizzle ORM（最新稳定）**。草稿正文以 `jsonb` 存 Block AST；关系字段用强 schema 表。**恰好 7 张表**（Spec §6，锁定）：users / topics / drafts / edit_trails / model_configs / source_configs / usages。topics 唯一索引 `(platform, source_item_key, bucket_date)` 保证采集幂等。**不引 pgvector**（Spec Out-of-Scope，过度设计）。

## Consequences
- 正面：单库覆盖关系与半结构化；Drizzle 类型安全、迁移可控；与 Lighthouse 部署一致。
- 负面：需维护 Drizzle 迁移；中文全文检索弱（MVP 用 ILIKE 足够）。
- 关联：db/schema.ts（唯一来源）、ADR-001（部署）、ADR-002（Block AST JSONB）。
