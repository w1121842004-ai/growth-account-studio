# ADR-006: 可配置加权选题筛选，不引向量检索

## Status
Accepted — Spec ADR-006 锁定（2026-08-16）。

## Background
F1 选题雷达需热度×相关度×竞争度评分与重复度预警。是否引入向量检索/模型训练做语义匹配？

## Decision
**评分公式可配置加权**（权重存 settings/ topics rationale，默认 `score = 0.45·heat + 0.40·relevance − 0.15·competition`），相关度/竞争度由 LLM 批量判断（不爬正文，AC-09）。**不引入 pgvector / 向量检索**：单用户日均百条量级属过度设计（Spec Out-of-Scope）。重复度预警用跨平台共现 + 历史去重 + LLM 判断。

## Consequences
- 正面：MVP 够用、零额外基础设施；权重可随运营经验调参。
- 负面：相关度/竞争度为 LLM 估算，精度有限（MVP 可接受）；语料超万条再评估向量检索。
- 关联：db/schema.ts topics（relevance/competition/score）、openapi /topics/score、ADR-007。
