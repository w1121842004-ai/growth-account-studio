# ADR-002: Block AST + 双渲染器（核心决策）

## Status
Accepted — Spec C-1 锁定（2026-08-16）。

## Background
R-1 验证：微信编辑器认内联 style、头条编辑器（ProseMirror）剥内联 style，「一套 HTML 兼容双平台」前提不成立。原 PRD 排版假设被推翻（Phase 1 强制修正 B-1）。

## Decision
引入 **Block AST** 中间表示（权威定义 `schemas/block-ast.schema.json` + `block-ast.types.ts`）：无 CSS、type 枚举固定、marks 落 inline 节点。由 Tiptap 3 产出，再经**两个独立渲染器**消费：
- 微信渲染器：全内联 style + `<section>` 嵌套（renderer-rules.ts WECHAT_RULES）。
- 头条渲染器：零 inline style + 语义标签 + Unicode 层级（TOUTIAO_RULES）。
渲染规则全部 config 化（renderer-rules.ts），不散落硬编码；每个渲染器配快照测试（R-7）。

## Consequences
- 正面：彻底解决双平台不兼容；编辑一次、双端预览一致；平台规则变动改配置+快照即可。
- 负面：需实现两个渲染器 + AST 校验器 + Tiptap→AST 适配器。
- 关联：block-ast.*、renderer-rules.*、ADR-011（Tiptap）、openapi /render 端点。
