# 页面提示词 · 双平台预览导出（Dual-Platform Preview & Export）

- 路由：`/drafts/:id/preview`　｜　对应 API：`GET /drafts/:id/render?platform=wechat|toutiao` + `POST /export`
- 设计 Token 主题：暖纸白 / 松绿
- 关键：双平台预览必须是**两个独立视图**，不是一个预览适配两尺寸（架构师硬约束）

## 布局
两个独立手机框并排（桌面）/ 上下堆叠（移动）+ 下方操作栏（复制/导出 + 发布 checklist）。
- 左框：微信视图（完整视觉层次）
- 右框：头条视图（极简 Unicode 层级）

## 区块
1. 微信手机框：封面图位（说明：封面人工上传，域名限定 mmbiz.qpic.cn）+ 双色标题 + 引用块 + 分割线 + 卡片，消费 `--wx-*` 内联预设。
2. 头条手机框：纯文字 + `◆`/`○`/`▶`/`【】`/`「」` + 留白节奏，零颜色零边框，消费 `--toutiao-*` 符号。
3. 操作栏：`复制微信 HTML` / `复制头条文本` / `导出`（lucide `Copy`/`Download` 20px）+ 发布 checklist（强制）。
4. AI 标识：两框均含文字「本文含 AI 辅助创作」（微信额外 `--ai-line` 细线）；不可关闭（C-5）。
5. 发布 checklist：☐ 已在头条勾选「AI 生成/辅助创作」☐ 公众号已保留 AI 标识（C-6）。

## 5 态
- Loading：双框骨架（`--accent-soft` 微光）。
- Empty：「还没有内容可预览，先去生成或编辑」。
- Error：「微信渲染失败（样式超限）」/「头条渲染失败」+ `重试`。
- Populated：双框完整，内容主体一致、仅适配项差异（AC-04/AC-07）。
- Edge：头条超长「正文超 2000 字，建议拆分」；微信封面缺失提醒「请先上传封面」。

## 双平台能力差异（标注于两框下方，给用户预期）
| 能力 | 微信视图 | 头条视图 |
|------|----------|----------|
| 颜色/背景/圆角/边框 | ✅ | ❌ |
| 标题层级 | 内联字号/字重/颜色 | `◆`/`○` 符号 |
| 图片 | 仅封面 | 无 |
| inline style | 全支持 | 全剥离 |
| emoji | 不限 | ≤2 种且不连续 |

## 对应 Token
微信框 `--surface`+`--wx-*`；头条框 `--bg`+`--fg`+`--toutiao-*`；手机框 `--border`+`--radius-xl`；checklist 达标 `--success`；AI 标识 `--ai-line`+`--accent`；图标 lucide 16/20/24。
