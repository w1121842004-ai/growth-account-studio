# 页面提示词 · 选题池（Topic Pool）

- 路由：`/topics`　｜　对应 API：`GET /topics`（domain/platform 筛选、score 排序）
- 设计 Token 主题：暖纸白 / 松绿
- 寄存器：产品型；DENSITY=4（留白优先）；VARIANCE=5（左对齐标题+筛选栏，不居中 Hero）

## 布局
全局框架：桌面左侧 Sidebar（导航）+ 主区；移动底 TabBar。
主区 = 顶部筛选栏 + 右上「智能挖掘选题」CTA（松绿）+ 下方选题卡网格（桌面 2 列 / 移动 1 列）。

## 区块
1. 筛选栏：领域 chips（成长/职场/情感/学习）、情绪（温暖/犀利/治愈）、平台（公众号/头条/双平台）、排序（热度/竞争度/评分）、搜索框（带 lucide `Search` 图标 16px）。
2. 主操作：`智能挖掘选题` 按钮（Primary，`--accent`）。
3. 选题卡（`--surface` + `--border` + `--radius-lg`）：标题（`--font-display`）、来源标签（`--accent-soft` 底 + `--accent` 字 + lucide `Flame`/`History`/`Lightbulb` 16px）、适配平台图标（lucide `MessageCircle`/`Newspaper` 16px）、热度（`--font-mono` + `--muted`）、竞争度、重复度预警、`加入选题` 按钮（Secondary）。

## 真实内容示意（无占位）
- 卡1：「用 AI 工具做年度复盘，我悟到的 3 件事」｜来源：头条热榜（lucide `Flame`）｜平台：双平台｜热度 8.4万｜竞争度 中｜`加入选题`
- 卡2：「晨间仪式感：不靠意志力也能早起」｜来源：你的历史高赞（lucide `History`）｜平台：公众号｜热度 3.1万｜竞争度 低｜`加入选题`
- 卡3（预警）：「普通人如何用碎片时间学英语」｜来源：知乎热帖（lucide `Lightbulb`）｜平台：头条｜热度 12万｜⚠ 重复度预警：与近 7 天爆款高相似（lucide `AlertTriangle` + `--warn`）｜`查看差异`

## 5 态
- Loading：骨架卡（`--accent-soft` 微光扫过）+ 顶部「正在挖掘高潜选题…」+ 预计 8s。
- Empty：「还没有选题。输入你的赛道，让选题雷达帮你找方向」+ 示例「个人成长 / AI 提效」+ `智能挖掘` 按钮。
- Error：「选题雷达暂时连不上（采集源超时）」+ `重试` + `降级：用本地缓存`。
- Populated：上述卡片网格，筛选/排序实时生效。
- Edge：超长标题截断（…）；成本上限提示「本月采集额度将用尽，剩余 120 次」。

## 对应 Token
卡片 `--surface`+`--border`；来源标签 `--accent-soft`+`--accent`；热度 `--font-mono`+`--muted`；预警 `--warn`；CTA `--accent`；所有图标 lucide 16/20/24。
