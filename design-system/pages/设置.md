# 页面提示词 · 设置（Settings / 模型配置）

- 路由：`/settings`　｜　对应 API：`GET /settings` + `PUT /settings`、`GET /models` + `PUT /models/:id`
- 设计 Token 主题：暖纸白 / 松绿

## 布局
左侧设置分组导航（人设语调 / 模型切换 / 默认排版 / 合规）+ 右侧表单卡片。

## 区块
1. 人设语调：昵称 + 人设描述 + 默认语调（温暖/克制/犀利，单选 chip）+ 示例语气预览。
2. 模型配置：主模型（混元 Hy3）+ 备选（智谱 GLM-4.6 / 通义 Qwen Plus）状态点（lucide `Circle` 绿/黄/红 16px）+ 切换。
3. 默认排版偏好：默认模板（极简/书卷/分栏）+ 默认平台（公众号/头条/双平台）。
4. 合规提示：AI 标识不可关闭说明（lucide `ShieldCheck` 20px + `--accent`）。

## 真实内容示意（无占位）
- 人设：「小林 · 用 AI 助力自我成长的记录者」语调 温暖
- 模型：主 混元 Hy3（状态 正常，绿点）｜备选 智谱 GLM-4.6（状态 待命，黄点）
- 排版：默认 书卷｜默认平台 双平台
- 合规：「导出正文自动注入『本文含 AI 辅助创作』，且不可关闭（平台合规要求）」

## 5 态
- Loading：保存中 spinner + 「正在保存…」。
- Empty：未配置「先填一下你的人设语调，生成的稿子会更像你」+ 示例。
- Error：「模型 Key 无效（401）」+ `重试` + `改用备选模型`。
- Populated：已保存态，分组导航高亮当前。
- Edge：模型不可用「主模型离线，已自动切备选，输出格式一致」（AC-08）。

## 对应 Token
表单 `--surface`+`--border`；输入 focus `--focus-ring`；选中/开关 `--accent`；模型状态点 `--success`/`--warn`/`--danger`；图标 lucide 16/20/24。
